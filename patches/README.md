# patches/

New data layers go here: `mars_terrain.csv`, `mars_temps.csv`, `rock_GLiM.csv`, `impact_craters.csv`. One row per dataset in SOURCES.md.

Each file here is a drop-in addition to the data. Add a SOURCES.md row for every file before you commit it. Don't edit the files in `data/` to add a layer; add it here instead.
